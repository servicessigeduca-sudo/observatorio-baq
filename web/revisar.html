Uso interno del equipo

Revisar casos

Publica, descarta o corrige los casos que arma el scraper. Los cambios se guardan en el repositorio y la página se actualiza sola en unos minutos.

Entrar

Para guardar cambios necesitas una clave de GitHub con permiso de escritura en el repositorio. Se crea una sola vez:

  1. Abre GitHub → Fine-grained token.
  2. En Repository access elige Only select repositories → observatorio-baq.
  3. En Permissions → Contents elige Read and write.
  4. Crea la clave, cópiala y pégala aquí.
